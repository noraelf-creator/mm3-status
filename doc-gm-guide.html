3. 各段階の手順

V（疑惑投票）

  1. 全員が伏せて「自分以外の一人」を書き、同時に公開
  2. V1〜V5は一票1点、最終は一票5点。投票者・投票先・累積を疑惑表に記入して公開
  3. V直後に次の魔女を決める：まだ魔女をしていない人のうち、累積疑惑最多→今回の得票最多→優先順
  4. 前のDで廃墟に隠したカードは、このVの確定で解除（隠した履歴は残る）

R（魔女ゲーム）

  1. 人間4人は行き先、魔女は襲撃地点を伏せて選び、同時に公開
  2. 得点：捕まった人間−5、逃げた人間＋1、魔女は1人捕まえるごとに＋5（塔は人間＋3、魔女＋7／人）
  3. 能力回数を記録：逃げた人間は選んだ地点を1回（橋は襲撃地点のまね）、魔女は捕獲人数分の襲撃地点
  4. 魔女が橋を襲撃した時だけ、この時点で能力名の配分を宣言させ、記録する
  5. 検算：その回の点の増減を全員分足して、表と合っているか確かめる

  4. 会話：残り時間。密談は3分まで

4. GMの裁定（迷った時）

場面 裁定
モリミに「私の一撃で死んだ？」と聞かれた 「あなたが知っているのは、打ったことと倒れたことまで。結果は調べて確かめて」。致命傷だったと先に教えない
他のPCに「私の工作は失敗した？」と聞かれた 失敗も成功も先に保証しない。「記録で確かめて」
早い段階の推測（「全員が殺そうとしたのでは」など） 肯定も否定もしない。告白や推理を禁止して順番を強制しない
HOに書いていないことを聞かれた 原則「その人物は見ていない／覚えていない」。推理に関わる新しい事実を足さない
アヤツジに「06分に校了室の中を見たか」と聞かれた 「廊下から扉の隙間越しに一瞬。部屋の中は見回していない」
「廊下から備品室の中が見えるのか」と聞かれた 「備品室の扉は開いていて、操作盤と灯は廊下から見える」
12分の時計の操作が卓に出た後（E15・E16・C1・M3など）に、「12〜13分に備品室ですれ違わなかったのか」と聞かれた 「12分のアリスガワは操作のあとすぐ廊下へ出た。13分のヨネザワも廊下のアヤツジも、そのアリスガワを気に留めていない。アリスガワの目に残ったのも、操作盤のヨネザワだけ」。12分の操作が卓に出る前は、原則どおり「その人物は見ていない」とだけ答える（アリスガワのM3の中身なので）
「記録機だらけなのに、なぜ誰も気にしないのか」と聞かれた 「劇中はアガサが作ったゲームの舞台。記録機の多さは、この作品の約束事」（R01の「校了会は記録が命です」）
「なぜアガサは看板を移したのか」「なぜ録音を予約したのか」 「記録に理由は残っていない」。推理には関係しない
現実の医学・薬・電気の知識で結論を覆そうとする 「確定所見は事件の中の事実です」（C0）
Xの色や位置、PC番号から答えを決めようとする 「Xは未確認の印だけ。色や位置に答えはない」
「私に入れて」と頼んだ／根拠なく「私が犯人」とだけ言って票を求めた 注意する（共通HO §10）。自分の行動を話すこと自体は自由
自分の秘密主条件を見せようとした 止める。言い換えて伝えるのも禁止
アリスガワの申請 出来事と出典がそろえば、該当する頁を本人だけに渡す。当てずっぽうは「まだ渡せない」とだけ言う。条件はM用紙の表のとおり。申請はメモで受け、結果だけ本人に渡す。会話を止めない
「誰がどのカードを持っているか」を聞かれた 公開情報。台帳を見せてよい（本文は見せない）
モリミの回答の「場所」 回答鍵のとおり採点する。ヨネザワは「備品室から、校了室の展示卓を狙って」まで要る。用紙の見出しで両方を書くよう促している
隠されたカードの中身を口で話した 止めない（隠すのは原文だけ）
奪ったカードの「記録者」 変わらない。書かれている「見た人」は最初の持ち主
